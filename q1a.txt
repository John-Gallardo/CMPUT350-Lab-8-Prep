For theta = 0 we have:
[1, 0, 0]
[0, 1, 0]
[0, 0, 1]

For theta = pi/2 we have:
[0, -1, 0]
[1,  0, 0]
[0,  0, 1]

x-axis points right and y-axis points down

if we multiply p = [1, 1, 1] with the matrix for theta = 0:
it's still [1, 1, 1]

if we multiply p = [1, 1, 1] with the matrix for theta = pi/2:
it's now [-1, 1, 1]

-> x went from 1 to -1
if we drew out the 2D axis, it's [1, 1] to [-1, 1].
with the y-axis down, visually speaking increasing theta would mean a clockwise rotation.

if the y-axis points up, visually speaking it would be counterclockwise.
